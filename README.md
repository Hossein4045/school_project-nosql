# ارائهٔ تعاملی NoSQL — حسین حسنی

یک وب‌سایت ارائهٔ فارسی، راست‌چین و واکنش‌گرا برای نمایش تحقیق «دیتابیس از صفر تا NoSQL». پروژه فقط فرانت‌اند است و به بک‌اند یا Docker نیاز ندارد.

## امکانات
- ۱۵ اسلاید از تعریف دیتابیس تا مدل‌های NoSQL، مقایسه و منابع
- ناوبری با دکمه‌ها و کلیدهای جهت‌نما
- فهرست اسلایدها و حالت تمام‌صفحه
- طراحی واکنش‌گرا با Tailwind CSS
- JavaScript؛ بدون TypeScript

## اجرا
پیش‌نیاز: Node.js نسخهٔ 18.18 یا جدیدتر.

```bash
npm install
npm run dev
```

سپس آدرس `http://localhost:3000` را در مرورگر باز کنید.

برای ساخت نسخهٔ production:

```bash
npm run build
npm start
```

## شخصی‌سازی
محتوای اسلایدها در آرایهٔ `slides` در فایل `src/app/page.js` قرار دارد. رنگ‌ها و استایل‌های پایه در `tailwind.config.js` و `src/app/globals.css` هستند.

فونت Vazirmatn از Google Fonts بارگذاری می‌شود؛ اگر اتصال اینترنت در دسترس نباشد، فونت‌های جایگزین استفاده می‌شوند. برای ارائه نیازی به API عکس نیست؛ گرافیک‌ها با CSS و آیکون‌های Lucide ساخته شده‌اند.
